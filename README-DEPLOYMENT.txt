DEPLOYMENT
1. Upload ALL contents of this package to the GitHub Pages/site repository, preserving folders.
2. Keep the hidden .htaccess file if the same files are also deployed to Apache hosting. GitHub Pages does
   not process .htaccess; clean directory URLs work through index.html folders.
3. Commit and push the complete package.
4. In Google Search Console, submit:
   https://yoga1hour.com/sitemap.xml
5. Use URL Inspection for /blog/ and a representative sample of the new School and Corporate URLs.
6. Request indexing only after the live URLs return successfully.

IMPORTANT SEO NOTE
No responsible implementation can guarantee a page will rank quickly, rank first, or be indexed on a
specific date. This implementation improves crawlability, page structure, relevance signals, internal
linking and answer-oriented content; search engines independently decide crawling, indexing and ranking.
Avoid submitting duplicate or alternate URLs for the same article.
