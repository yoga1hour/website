# Yoga 1 Hour — Raw Website Files

Open `index.html` in a browser. No installation or build step is required.

## Before publishing
- Replace the sample phone number and email address.
- Replace Unsplash placeholder image URLs with licensed brand images.
- Update names, session descriptions and schedule with verified business details.
- Connect the enquiry form to your CRM, Formspree, Netlify Forms or backend. The included form only shows a front-end confirmation.
- Add privacy, terms, cancellation and health-disclaimer pages.
